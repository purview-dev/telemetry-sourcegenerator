## Parameter Exclusion Flow

```
FOR EACH PARAMETER:
    ?
    ?? Is Activity/ActivityContext/ActivityLink?
    ?  ?? YES ? Exclude from: Logging, Metrics
    ?           Include in: Activities
    ?
    ?? Is TagList?
    ?  ?? YES ? Exclude from: Logging
    ?           Include in: Activities, Metrics
    ?
    ?? Is Func<T> / Func<Measurement<T>>?
    ?  ?? YES ? Exclude from: Logging, Activities
    ?           Include in: Metrics (Observable only)
    ?
    ?? Is DateTimeOffset (named 'startTime')?
    ?  ?? YES ? Exclude from: Logging, Metrics
    ?           Include in: Activities
    ?
    ?? Is First Numeric Parameter (Metrics present)?
    ?  ?? YES ? Exclude from: Logging
    ?           Include in: Metrics, Activities
    ?
    ?? Otherwise
       ?? Include in: All Targets
```

## Error Priority

When multiple errors could apply, report in this order:

```
1. Scoped + Activity/Bool Metrics
   "Scoped logger incompatible with Activity creation or bool metrics"

2. Activity + Bool Metrics (no Observable)
   "Cannot combine Activity return with bool metrics"

3. Observable + Bool Return
   "Observable metrics cannot return bool"

4. AutoCounter + Non-Void Return
   "AutoCounter must return void"

5. Invalid return type
   "Only void, bool, Activity?, or IDisposable are valid"
   Note: Task/ValueTask are NOT valid for any target
